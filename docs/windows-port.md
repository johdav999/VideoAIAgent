# Native Windows Cinetic adapter

The initial sharp-render subset has been extended to the pinned Cinetic v1.0.0 feature set. Use [the current Windows command guide](windows-cinetic.md) for setup, both engines, rendering/delivery, fonts/brand assets, QA, the repository-local direction skill and lock recovery.

The [complete feature acceptance report](acceptance/windows-cinetic-complete.md) supersedes the scope limitations in the historical [first-render report](acceptance/windows-first-render.md). The [local API](local-api.md) retains its declarative product-template contract and has separate [job-service evidence](acceptance/windows-job-service.md).

No fork, global skill installation, Bash, WSL or Unix symlink is used. Customer-film creative approval, hosted AI orchestration, VC integration and Azure deployment remain separate acceptance targets.
