# Production direction

Turn a brief into a reviewable treatment, timeline, asset manifest, and render request. Coordinate Cinetic through the adapter. Keep the production workflow independent of the Virtual Company client.

The implemented local directing workflow is [skills/cinetic-windows/SKILL.md](../../skills/cinetic-windows/SKILL.md). It covers concepts, treatment, brand, authoring, scoring, critique and delivery through the native adapter. Load it explicitly in the working agent; it is not globally installed.

A hosted autonomous model provider and an HTTP brief-to-film agent remain planned. The existing job API accepts a declarative product specification.
